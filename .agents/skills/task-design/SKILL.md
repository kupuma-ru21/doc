# スキル名
タスク設計

## やること
1. 仕様理解フェーズ
  - 仕様が記載されたMarkdownファイルのディレクトリを指定して、ファイルを読み込む
  - ディレクトリ指定がない場合は、決して次に進まない

2. 読み込んだ仕様を確認、以下のどれが必要か確認
  - テーブル設計
  - バックエンド実装
  - フロントエンド実装

4. 2で該当したもののうち、どの部分から実装するかAskUserQuestionツールを使って質問する
  - テーブル設計を選択した場合、「@~/.Codex/skills/table-design/SKILL.md」を実行する
